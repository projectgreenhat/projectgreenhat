Automated customer support pipeline — Gmail trigger, GPT-powered AI agent (Flo) that queries a RAG knowledge base, auto-escalates unresolvable issues to ClickUp with a generated ticket number, and replies via Gmail. Includes live KB sync from Google Drive.

`N8N` `GPT-4o-mini` `Supabase pgvector` `Gmail` `ClickUp` `Google Drive`
